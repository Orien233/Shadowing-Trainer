# 多语言行为与边界

简体中文 | [English](../en-US/multilingual.md) · [文档首页](README.md)

## 三种独立语言

| 设置 | 允许值 | 用途 |
| --- | --- | --- |
| `ui_locale` | `zh-CN`, `en-US` | 只控制界面文案和状态标签 |
| `learning_language` | 受控内容语言目录 | 新上传和新文本练习的默认正文语言 |
| `translation_language` | 受控内容语言目录 | 新句子翻译和 AI 说明的默认语言 |

改变 UI 语言不会翻译已保存内容。改变全局学习或翻译语言只影响之后创建的内容；Material 和 Text Practice 会保存自己的语言快照。

## 内容语言目录

后端接受以下规范 BCP-47 标签：

| 标签 | 语言 | 标签 | 语言 |
| --- | --- | --- | --- |
| `en` | 英语 | `zh-CN` | 简体中文 |
| `zh-TW` | 繁体中文 | `ja` | 日语 |
| `ko` | 韩语 | `es` | 西班牙语 |
| `fr` | 法语 | `de` | 德语 |
| `it` | 意大利语 | `pt` | 葡萄牙语 |
| `ru` | 俄语 | `ar` | 阿拉伯语 |

输入大小写和 `zh_cn`、`zh_tw` 中的下划线会规范化。未知内容语言会被拒绝。`auto` 只用于明确支持自动检测的 ASR 参数，不能作为学习语言；`und` 只用于后端明确表示未知语言的场景。

## 语言数据如何传递

| 工作流 | 行为 |
| --- | --- |
| 上传 | 请求提交内容语言和翻译语言，Material 保存两者 |
| 素材处理 | 内容语言传给 ASR 和分句，翻译目标取 Material 的翻译语言 |
| 收藏单词 | 按规范语言保存、查询和去重 |
| AI 文本 | 目标语言限制可用收藏，生成/导入保存目标和翻译语言 |
| TTS | 排队时冻结两种语言，任务语言优先于 Provider 默认语言 |
| 录音评分 | 从 Sentence 所属 Material 读取内容语言并传给 ASR 和评分策略 |

当源语言与翻译语言相同时，翻译服务直接返回原文而不请求 LLM。翻译属于增强步骤：缺少可用 LLM 或单句翻译失败时，素材和 TTS 练习仍可使用，译文留空并由 UI 按界面语言显示状态。

## 收藏和 AI 文本

收藏词使用 Unicode NFKC 和 `casefold` 生成去重键，同时保留用户看到的原始大小写和组合附加符。随机选择只查询目标语言；手动选择也会验证每条收藏的语言，跨语言混选返回校验错误。

LLM Prompt 使用语言名称和 BCP-47 标签，但不绑定具体厂商。正文中的已使用词检查针对空格语言使用 token 边界，对无空格文字使用规范化子串，避免把英语 `he` 错算为 `the` 的一部分。

## Provider 语言限制

任务显式语言优先于 Material/Text Practice 快照，快照优先于 Provider 默认值。当前服务会拒绝 TTS 任务用与 Text Practice 目标语言冲突的显式覆盖，避免合成语种与 Material 标签不一致。

- OpenAI ASR 在需要时接收主语言码，例如 `zh-CN → zh`。
- MiMo ASR 只接受 `auto`、`zh`、`en`；其他语言使用 Local Whisper 或明确失败。
- Local Whisper 在选中场景中接收任务语言，并复用进程内模型缓存。
- OpenAI TTS 默认只在内部元数据记录语言，不自动发送兼容性不确定的 `instructions`。

更多路由规则见 [Provider 指南](providers.md#asr-场景路由)。

## 分句与评分边界

素材分句优先使用 ASR 的 segment 和 word timestamp。中文、日文片段拼接时不额外插入空格，其他目录语言默认以空格连接。TTS 分句支持常见拉丁、中日韩、阿拉伯和天城文终止符，并避免在小数和域名内部的句点切分；它仍是保守规则，不是完整语言学分词器。

评分会公开实际对齐模式，而不是把所有语言都称为“单词准确率”：

| 内容语言 | 对齐模式 | 支持级别 |
| --- | --- | --- |
| 英语 | word | full |
| 中文、日语、韩语 | Unicode character | limited |
| 其他目录语言 | Unicode token | basic |

英语 contraction、filler、单复数和轻微词形规则不会用于非英语。评估的 `raw_metrics` 保存 `language`、`alignment_mode` 和 `support_level`，前端据此显示词、字符或 token 准确率。中文/日文收藏显示使用浏览器 `Intl.Segmenter`，评分 token 只负责投射状态，不会替换或破坏原句标点与空格。

韵律、音高和时长指标在多语言下可提供练习参考，但尚未针对所有语言校准，应结合对齐结果和实际听感理解。
