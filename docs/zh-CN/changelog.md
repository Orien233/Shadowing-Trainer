# 版本记录

简体中文 | [English](../en-US/changelog.md) · [文档首页](README.md)

本文保留旧版 README 中的版本演进信息。使用方法以当前[安装指南](getting-started.md)和[用户指南](user-guide.md)为准。

## v0.4.1

- 将 UI 语言、学习内容语言和翻译语言拆分并持久化，新增中英文界面。
- Material、Text Practice、ASR、翻译、TTS、收藏词和评分形成完整语言传递链。
- 引入受控 BCP-47 目录、多语言分句和明确的评分支持等级。
- Local Whisper 改为可选安装，并按 ASR 场景和 Provider 语言能力回退。
- 强化 TTS Job 快照、编辑失效、输出隔离和安全重试。
- 运行源码目录从历史版本名迁移为版本中立的 `shadowing/`。

## v0.4

- 新增 LLM 文本生成、用户文本导入和句级 TTS 练习闭环。
- 引入 Provider Factory、Adapter Catalog、用户能力/格式声明和内置快捷模板。
- 远程支持收敛为 OpenAI Chat、OpenAI Audio 与 MiMo；历史 Adapter 不再注册。
- 增加 LLM、TTS、ASR 配置档 CRUD、密钥遮罩和分级测试。
- 增加素材转写与录音评估两个独立 ASR 路由设置。
- TTS 将 Provider 输出规范化为句级 WAV，并合并整篇 MP3 后复用 Material/Sentence 训练结构。

## v0.3.2

- 素材处理和录音评分迁移到 SQLite 持久化 Job，支持进度、失败重试和重启恢复。
- 评分快照合并到主数据库，并使用 Alembic 管理升级。
- 上传改为流式临时文件与 ffprobe 校验；视频增加大小限制、转码和音轨提取。
- 录音面板增加权限错误、倒计时、试听、重录和任务状态。
- 前端 API 地址支持 `VITE_API_BASE`。

## v0.3.1

- 新增参考句与用户 ASR 文本的词级对齐，识别正确、替换、漏读、插入、重复和 filler。
- `raw_metrics` 保存对齐结果，重新进入素材时可恢复每句最新评分。
- 训练页和评估页增加词级高亮。
- 分句保存更精确的词边界，句级音频裁剪减少首尾截断。
- 增加词级对齐、媒体安全和训练页面回归测试。

## v0.3

- 评分前增加基于 VAD 的静音裁剪，并在失败时安全回退。
- 引入素材/句子最新评分快照，支持从主评估表回退读取。
- 强化音视频识别、切片边界、时间轴同步和媒体错误提示。

## v0.2

- 上传后自动触发素材处理，并支持重新处理和级联删除。
- 素材列表增加操作菜单、进度和删除后的选中项兜底。
- 时间轴区分句子与静音段，增加自动播放和单段循环。
- 练习页加入视频播放器并与句子时间轴双向同步。

## 初始版本

- 建立 FastAPI、SQLModel/SQLite、React/Vite 基础应用。
- 完成素材上传、本地 Whisper 转写、分句、翻译、逐句播放、录音和基础评分。
