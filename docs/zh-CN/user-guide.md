# 使用指南

简体中文 | [English](../en-US/user-guide.md) · [文档首页](README.md)

## 1. 设置语言

页面顶部和“设置”中有三个彼此独立的选项：

- **界面语言**只控制按钮、提示和状态文案。
- **学习语言**是新上传素材和新文本练习的默认正文语言。
- **翻译语言**是新句子翻译和 AI 说明的默认语言。

修改全局默认值不会改变已有素材；每条 Material 和 Text Practice 都保存自己的语言快照。完整规则见[多语言行为](multilingual.md)。

## 2. 配置模型

进入“设置”，在快捷模板中选择 OpenAI Chat、OpenAI TTS、OpenAI ASR、MiMo TTS 或 MiMo ASR。模板不会直接参与业务调用；保存后会生成一个可改名、启用、测试和设为默认的独立配置档。

每个配置档只会执行用户勾选的能力和格式。至少需要：

- AI 文本：默认 LLM 同时启用 `generate_text` 与 `generate_json`，并选择 JSON 输出方式。
- TTS：默认 TTS 启用 `synthesize`，并至少选择一种输出格式。
- 远程素材转写：默认 ASR 启用 `transcribe` 与 `word_timestamps`。
- 远程录音评估：默认 ASR 启用 `transcribe`，并支持当前内容语言。

MiMo ASR 没有词级时间戳，因此不能单独承担素材转写。详细配置见[模型与 Provider](providers.md)。

## 3. 上传并处理素材

1. 在练习面板选择内容语言和翻译语言。
2. 填写标题并选择音频或视频。
3. 上传后等待持久化 Job 完成媒体标准化、ASR、分句、翻译和句级音频生成。
4. 处理完成后从素材列表进入训练。

视频会先转换为可训练媒体并提取音轨。已知文本通过 TTS 创建的素材不会再次用 ASR 识别正文。

处理失败时，素材卡片会显示阶段和可读错误。修复 Provider、FFmpeg 或 Local Whisper 配置后，可以重试或重新处理。程序重启后，持久化任务会恢复。

## 4. 收藏与管理单词

在训练句子中点击单词即可收藏。收藏记录包含语言，因此同一拼写在不同语言下是不同条目。

- 词库只显示当前选择语言的收藏。
- AI 文本的随机和手动选择只使用目标语言相同的收藏。
- 后端会拒绝将不同语言的收藏混入同一篇生成练习。
- 原始显示文本会保留大小写和 Unicode 写法；去重使用规范化键。

## 5. 生成或导入 AI 文本

进入“AI 文本”面板：

1. 选择随机数量，或手动勾选收藏单词。
2. 选择预设主题或填写自定义主题。
3. 设置目标语言、翻译语言、难度和篇幅。
4. 点击生成；LLM 会返回标题、正文、已使用词、未自然使用词和可选说明。
5. 在提交 TTS 前可以继续编辑标题和正文。

也可以跳过 LLM，直接切换到文本导入并粘贴内容。导入与生成共用同一 Text Practice 和 TTS 流程，因此即使没有 LLM，文本编辑和导入仍可使用。

## 6. 创建 TTS 练习

为文本选择语速、音色、口音、性别或模型等参数。不同协议不支持的字段可能被忽略或由后端明确拒绝。

提交后，TTS Job 会冻结正文、标题、目标/翻译语言、Provider 和参数，然后：

1. 按语言感知规则切分句子。
2. 逐句合成音频。
3. 将句级音频规范化为 24 kHz 单声道 WAV。
4. 合并整篇 MP3 并生成时间边界。
5. 创建 Material、Sentence 和句子翻译。

完成后点击进入练习，即可沿用普通素材的逐句播放、录音和评分页面。编辑或重新排队会使旧 Job 失效，避免旧结果覆盖新文本。

## 7. 跟读、录音与评分

- 使用上一句、下一句、时间轴、循环和自动播放控制练习。
- 视频素材保留视频画面，音频与当前句边界同步。
- 在非静音段录音，可试听、重录并提交评分。
- 评分 Job 完成后显示完整度、流利度、同步度、发音及对齐反馈。
- 英语提供完整词级对齐；其他语言会按实际支持程度显示字符或 Unicode token 准确率。

评分是练习反馈，不是考试成绩。多语言评分限制见[分句与评分边界](multilingual.md#分句与评分边界)。

## 8. 任务失败与重试

素材处理、录音评估和 TTS 都使用持久化 Job。失败后先阅读错误并修复根因：

- `404 Not Found` 通常表示把 Base URL 填到了要求完整 Endpoint 的配置中，或反之。
- 缺少能力时，前端会禁用入口；后端也会重复校验。
- Local Whisper 不可用时，安装可选依赖并在设置中检查运行状态。
- TTS 旧任务若已被编辑或新任务取代，通用重试会返回冲突；应从当前文本重新创建 TTS Job。

任务恢复不会绕过语言、Provider 能力或快照一致性校验。
